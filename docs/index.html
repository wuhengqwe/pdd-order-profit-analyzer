    模板清单
    使用说明与计算规则

    报表与成本

    订单需要商品 ID、订单号、成交时间、订单状态、数量、商家实收和规格编码。推广表需要商品 ID 和总花费。使用自有成本表时，请将编码按文本保留前导零。下载成本表模板

    订单与利润

    订单按订单号去重，排除未支付、取消和退款成功记录。订单数与商品件数分别统计。利润扣减商品成本、包装损耗、推广费、税费、技术服务费、运费和退款损耗预留。莆田默认按 1.5%、义乌按 5% 计税。优先按报表里的明确发货仓。缺发货仓时按成本匹配判定，跨仓组合按仓库成本比分摊实收。缺成本、推广花费或计税仓的链接，利润留空。

    同模板识别

    有上架清单时按清单中的实际模板标识归并。其余链接按成交规格编码与最常见的商家实收单价归并。同组复用前请核对完整在售 SKU。

    「模板最高单量链接」每组只展示保留订单最多的链接，订单数相同时优先近 30 天订单数较多的链接。

    出单率

    模板保留订单数除以该模板已上架链接数，单位为单/链接。分母包括清单中的零单上架链接。历史订单与上架清单按商品 ID 关联，清单的统计范围请与分析目的保持一致。
